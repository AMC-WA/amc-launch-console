Build plan

How this prototype becomes a working system on the Office 365 tenant you already license, with no off-the-shelf CRM or project tool.

Recommended stack

Data
SharePoint Lists

Six lists: Functions, Updates, Owners, Touches, Gates, Cadence. Row-level audit, versioning, 30M-row capacity. Zero added cost.

App
This page

Static page on GitHub Pages, Microsoft Entra sign-in, Microsoft Graph to the lists. Pinned as a tab in the AMC Partners team. Decision 5, 19 Oct 2026.

Automation
Power Automate

Digests on each partner's cadence, urgent posts to Teams and Outlook at once, due-date and gate warnings, Outlook events for every date.

Reporting
Power BI

Weekly pipeline report for the partner meeting; partner-load and gate dashboards embedded in the app.

AI search
Copilot Studio agent

Grounded on the six lists and the deal-file folders in SharePoint. Answers the search bar above in Teams chat too.

Database choice

OptionAdded costFit
Excel on OneDriveNoneNot recommended as the system of record. Four partners editing one workbook collide; no row-level audit; Power Automate triggers on Excel are unreliable. Keep Excel for the models and the target-list source.
SharePoint ListsRecommendedNoneIncluded in your licenses. Native to Power Apps, Power Automate and Teams. Version history on every row. Handles the 4,029-property universe with indexed columns. Easy to change a column without touching code.
Dataverse for TeamsNoneAlso included. Relational tables inside the team. Limits: 2 GB per team, app usable only inside Teams. A good second step if the list model gets strained.
Dataverse (full)About $20 per user per month for four seatsThe enterprise path: proper relationships, security roles, a model-driven app with built-in Kanban and calendar controls. Worth it after the first closing, when the controller and analyst join.
